# 《基于 Python Web 的本地文献综述工作台设计与实现》页面原型说明与组件清单

## 1. 文档目的
本文档用于说明系统的页面原型设计思路、页面布局结构、关键交互区块和组件清单，为后续 UI 设计、前端开发、系统演示和课程报告撰写提供依据。

## 2. 设计参考

### 2.1 LitLit 参考界面
LitLit 提供了较成熟的科研工作台式首页布局，其优点在于左侧导航清晰、中部输入区突出、任务入口明显，适合作为本系统的外层参考。

本项目不直接照搬 LitLit，而是基于其布局做减法设计：
- 保留工作台式左侧导航
- 保留中心任务输入区
- 删除推荐资讯、会员、登录、绘图和无关扩展功能
- 将首页入口收敛为“文献检索、论文研读、综述写作”三类核心任务流

### 2.2 Codex 参考界面
Codex 的界面风格更适合作为本系统内部工作区的参考，其特点在于：
- 左侧侧边栏用于导航与上下文切换
- 中央区域用于任务输入与任务执行
- 输出内容不是零散卡片，而是围绕当前任务形成连续工作区

本系统将借鉴这种“围绕任务形成连续工作区”的组织方式，用于论文研读页和综述写作页。

## 3. 总体原型思路

### 3.1 总体布局
系统采用“三段式工作台布局”：

- 左侧：全局导航区
- 中间：当前任务主工作区
- 右侧或下方：结果区、详情区或辅助信息区

其中：
- 首页偏“任务入口型”
- 文献检索页偏“结果列表型”
- 论文研读页偏“详情工作区型”
- 综述写作页偏“结构编辑型”

### 3.2 设计风格建议
- 风格关键词：克制、清晰、专业、轻量
- 色彩方向：浅色背景 + 深色正文 + 单一强调色
- 字体风格：避免花哨，突出学术工具属性
- 动效策略：仅在页面切换、任务开始、结果加载时使用轻微反馈
- 视觉目标：看起来像“科研工作台”，而不是“聊天机器人网页”

## 4. 页面原型说明

## 4.1 页面 P1：首页 / 项目入口页

### 页面目标
帮助用户快速进入某个研究项目，并从首页直接发起三类核心任务流。

### 页面布局

#### A. 左侧导航区
用于放置全局入口。

建议保留：
- Logo / 系统名称
- 新建项目按钮
- 项目列表入口
- 文献检索入口
- 论文研读入口
- 综述写作入口
- 历史任务入口

建议去除：
- 登录按钮
- 会员升级
- 推荐资讯
- 绘图工具
- 与课程目标无关的附加菜单

#### B. 中央欢迎区
用于传达系统定位。

内容建议：
- 系统名称
- 一句简短副标题
  例如：“面向科研综述写作的本地 AI 工作台”
- 当前打开项目概览

#### C. 任务发起区
这是首页最核心的交互区，不是通用聊天框，而是“任务启动器”。

应包括：
- 研究主题 / 检索要求输入框
- 三个任务按钮：
  - 文献检索
  - 论文研读
  - 综述写作
- 开始按钮

#### D. 最近项目 / 最近任务区
用于帮助用户恢复上下文。

可展示：
- 最近打开的项目
- 最近一次检索任务
- 最近一次研读任务
- 最近一次提纲生成任务

### 页面交互说明
- 用户进入首页后，优先看到当前项目或最近项目
- 用户在输入框中填写任务要求后，点击某一任务按钮进入对应页面
- 若未选择项目，则先引导创建项目或选择项目

## 4.2 页面 P2：文献检索页

### 页面目标
围绕特定研究主题完成候选文献检索、筛选、导入和 PDF 获取。

### 页面布局

#### A. 顶部任务栏
展示：
- 当前项目名称
- 当前任务类型：文献检索
- 返回项目首页按钮

#### B. 左侧检索条件区
用于设置检索输入和筛选条件。

包含：
- 研究主题输入框
- 关键词输入框
- 检索要求输入框
- 检索来源选择
- 年份范围筛选
- 排序方式
- 执行检索按钮

#### C. 中央结果列表区
展示候选文献结果列表，每条结果建议采用列表卡片形式。

每条结果建议展示：
- 标题
- 作者
- 年份
- 来源
- 摘要片段
- 是否可下载 PDF
- 导入项目按钮

#### D. 右侧操作与状态区
用于显示当前批量操作状态。

建议包括：
- 已选中文献数量
- 批量导入按钮
- 批量下载 PDF 按钮
- 当前下载状态
- 当前导入状态

### 页面交互说明
- 用户先设置检索条件，再查看结果
- 用户可单篇或批量导入文献
- 用户可直接发起 PDF 下载
- 导入后的文献应写入项目文献库

## 4.3 页面 P3：项目文献库页

### 页面目标
集中展示当前项目内所有文献，并支持筛选、排序和进入研读。

### 页面布局

#### A. 顶部工具栏
包含：
- 当前项目名称
- 文献总数
- 筛选条件概览
- 导出 BibTeX 按钮

#### B. 左侧筛选面板
包含：
- 状态筛选
  - 候选
  - 已读
  - 已纳入综述
- 标签筛选
- 年份筛选
- 来源筛选

#### C. 中央文献表格 / 列表区
建议以表格 + 状态标签的形式展示，便于管理。

列建议包括：
- 标题
- 作者
- 年份
- 状态
- 标签
- PDF 状态
- BibTeX 状态
- 更新时间

#### D. 右侧摘要信息区
当用户选中文献时，右侧显示简要预览：
- 摘要
- 备注
- 支持的快捷操作
  - 打开详情
  - 打开 PDF
  - 标记已读

### 页面交互说明
- 用户可以从这里完成项目级文献管理
- 双击或点击某篇文献可进入详情 / 研读页

## 4.4 页面 P4：论文详情 / 研读页

### 页面目标
围绕单篇论文建立结构化理解和研读记录。

### 页面布局

#### A. 顶部信息栏
展示：
- 论文标题
- 作者与年份
- 返回文献库按钮
- PDF 打开按钮
- 生成研读结果按钮

#### B. 左侧论文信息区
展示基础元数据：
- 标题
- 作者
- 年份
- 摘要
- 关键词
- 来源链接
- BibTeX
- PDF 状态

#### C. 中央结构化研读区
这是本页的核心工作区。

建议模块：
- 研究问题
- 研究目标
- 方法与技术路线
- 数据集 / 实验设置
- 主要结论
- 局限性
- 与当前研究主题的关系

#### D. 右侧用户笔记区
用于人工补充：
- 自由备注
- 标签
- 是否纳入综述
- 是否值得重点阅读

### 页面交互说明
- 用户打开论文后，可手动阅读 PDF，也可触发 Codex 生成结构化研读结果
- 生成结果允许用户编辑后保存
- 保存结果后应能被综述写作页继续调用

## 4.5 页面 P5：综述写作页

### 页面目标
基于已筛选和已研读文献生成综述准备材料，重点输出提纲和研究脉络。

### 页面布局

#### A. 顶部任务栏
展示：
- 当前项目名称
- 当前任务类型：综述写作
- 生成提纲按钮
- 保存结果按钮

#### B. 左侧文献选择区
用于指定生成提纲所使用的文献范围。

应包括：
- 文献列表
- 状态筛选
- 标签筛选
- 勾选纳入文献

#### C. 中央提纲工作区
这是页面的核心编辑区。

建议结构：
- 一级标题区
- 二级标题区
- 每个部分的简要说明
- 可编辑文本块

#### D. 右侧支撑文献区
用于显示每个提纲部分的参考依据。

建议展示：
- 对应文献标题
- 作者年份
- 关键结论摘要
- 跳转到论文详情按钮

### 页面交互说明
- 用户选择文献后触发提纲生成
- 提纲结果可人工修改
- 修改后的结果可保存为项目成果

## 4.6 页面 P6：历史任务记录页

### 页面目标
查看历史任务执行过程与结果，支持继续复用。

### 页面布局

建议包含：
- 任务类型筛选
- 时间筛选
- 任务记录列表
- 点击后查看历史结果

该页可作为增强功能页，不是 MVP 首屏重点。

## 7. 原型设计结论
本系统的页面设计应遵循“外层参考 LitLit，内层借鉴 Codex”的思路：外层采用清晰的科研工作台式布局，内层围绕具体任务组织连续工作区。通过删除通用聊天产品中与科研综述无关的入口，将界面聚焦在文献检索、论文研读和综述写作三类任务流上，从而形成真正服务于研究主题项目的软件界面。
